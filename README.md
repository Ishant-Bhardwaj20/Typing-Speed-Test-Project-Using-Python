# Typing Speed Tester
Typing Speed Tester is a simple Python project that helps users test their typing speed. The program randomly selects a sentence and asks the user to type it as quickly as possible.

The project measures the time taken to complete the test and calculates the typing speed in Words Per Minute (WPM). It also includes a function to compare the user's input with the original sentence and calculate typing accuracy.

This project uses Python's `random` module to select sentences randomly and the `time` module to measure the time taken by the user.

## Features
* Random sentence selection
* Typing time measurement
* Words Per Minute (WPM) calculation
* Typing accuracy calculation
* Simple command-line interface

## Technologies Used
* Python
* `time` module
* `random` module

This project was built to practice Python concepts such as functions, lists, string manipulation, user input, and working with built-in Python modules.
